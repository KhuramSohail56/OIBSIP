# Predictive - Premium Cyber Dashboard (Number Guessing Game)

A high-quality, interactive Desktop GUI application built using Java Swing. This project was developed as part of the **Java Development Internship** at **Oasis Infobyte** (Task 2). 

Instead of a standard console output, this application features a modern, responsive user dashboard with fluid custom animations, strict input filtering, and dynamic state tracking.

---

## ✨ Key Features

- **Adaptive Dashboard Layout:** Built using `GridBagLayout` anchors, ensuring the main gaming container (380x490px) stays perfectly centered, structurally sound, and crisp on any screen size or full-screen maximization.
- **True Glassmorphism UI:** Features a custom-painted midnight gradient background layered with translucent elements and modern neon purple-blue accents for a premium look.
- **Win Celebration Engine:** Triggers a live canvas explosion of randomized, multi-colored confetti particles cascading down the screen upon a successful guess.
- **Aggressive Shake Feedback:** Instantly triggers an elastic structural shake animation on the card panel when an empty input is submitted or when the user runs out of attempts (Game Over).
- **Dynamic Health Tracker:** Implements an interactive progression bar that dynamically shifts color (Green ➡️ Orange ➡️ Red) based on the remaining attempts.
- **Robust Input Filter:** Restricts the entry of non-numeric characters and strings, preventing invalid formats at the keyboard-stroke level.
